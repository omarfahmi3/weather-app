# 🌦️ Weather App

Simple weather application using OpenWeatherMap API.  
You can search any city and get real-time weather information.

---

## 🚀 Features

- Search weather by city name
- Shows temperature in °C
- Shows humidity and wind speed
- Dynamic weather icons
- Error message for invalid cities
- Works with Enter key or search button

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript (Vanilla JS)
- OpenWeatherMap API

---

## 🔑 API Used

OpenWeatherMap API:

https://api.openweathermap.org/data/2.5/weather

---

## ⚙️ How It Works

1. User enters city name  
2. API request is sent  
3. Data is returned from OpenWeatherMap  
4. UI updates with weather information  

---

## ⌨️ Controls

- Click search icon → get weather
- Press Enter → get weather
